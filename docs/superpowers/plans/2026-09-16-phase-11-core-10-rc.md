# Phase 11 — Core 1.0 RC (scope)

> **Kind:** Phase scope. **Not** an implementation plan.
> **Index:** [2026-09-16-xui-v1-phase-index.md](./2026-09-16-xui-v1-phase-index.md)
> **Do not code from this file.** Write a TDD plan only after Phase 8 is green and Phase 10 exists. Phase 9 may still be `0.x`.

**Goal:** Freeze Core public contracts and cut the first stable **Core** release candidate. DataGrid stays beta if needed. No new components unless an ADR already landed in earlier phases.

**Depends on:** Phase 8 (hardening evidence), Phase 10 (reference app). Phase 9 not required to be 1.0.

**Unlocks:** First `@xui/react` / `@xui/theme` / `@xui/tailwind` `1.0.0` (or `1.0.0-rc.n` then `1.0.0` per the release plan written at that time).

**Spec:** `docs/architecture.md` §62 Phase 11; §§54–55, 59, 61; ARCH-015, ARCH-020.

---

## In scope

- Freeze documented public contracts:
  - JavaScript exports
  - React props
  - TypeScript types / unions
  - semantic token names
  - documented CSS variables
  - documented `.xui-*` classes
  - documented `data-*` states
  - behavior defaults
  - keyboard behavior
- Independent SemVer: Core packages 1.x; `@xui/data-grid` may remain 0.x / beta (§59).
- Experimental APIs explicitly marked experimental.
- Changeset changelog for the RC.
- Re-run packed-artifact, RSC, no-tailwind, company-theme, a11y, visual gates on the release tarball.
- Confirm §23 / workspace / form-framework / realtime-store items were **not** added.
- Tag the architecture freeze + implementation evidence: “Architecture 100%, Core implementation at RC”, DataGrid separately.

## Out of scope

- New catalog items
- DataGrid 1.0
- `@xui/workspace`
- React 18 compatibility layer, CJS, UMD
- Reopening token architecture unless a Phase 8 finding produced an ADR

## Definition of done (§61 complete)

```text
Dark/light/company themes all work.
Semantic token contract is stable.
Tailwind utilities naturally override XUI defaults.
Core works without Tailwind.
Primitive engine details do not leak publicly.
Forms are compositionally complete.
Overlay focus/keyboard behavior is reliable.
Desktop layouts compose into complex applications.
RSC/SSR packaging is valid.
Package exports/types/CSS work from the real published artifact.
Accessibility-critical patterns have real browser tests.
Trading terminal reference app can be built without forking XUI.
Core 1.0 can release independently of DataGrid beta.
```

A company can build its own design system and domain trading UI on XUI without forking Core (`docs/architecture.md` §65).
